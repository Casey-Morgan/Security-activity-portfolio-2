## Watermarking Method

The watermark was applied using a Python-based DCT-style image watermarking method.

DCT stands for **Discrete Cosine Transform**. It is commonly used in 
image processing and compression. Instead of visibly placing text on the image,
the watermark was embedded into image frequency components.

The watermark text used was:

```text
B30_CYBER_PORTFOLIO_2026
```

The goal was for the watermark to be imperceptible, meaning that it should not be obvious to a normal viewer.


### Code

```python
from PIL import Image
import numpy as np
import cv2

INPUT_IMAGE = "original_ai_image.png"
OUTPUT_IMAGE = "watermarked_image.png"
WATERMARK_TEXT = "B30_CYBER_PORTFOLIO_2026"
STRENGTH = 6


def text_to_bits(text):
    data = text.encode("utf-8")
    bits = []
    for byte in data:
        for i in range(8):
            bits.append((byte >> (7 - i)) & 1)
    return bits


def embed_watermark():
    image = Image.open(INPUT_IMAGE).convert("RGB")
    image_np = np.array(image)

    ycrcb = cv2.cvtColor(image_np, cv2.COLOR_RGB2YCrCb)
    y_channel = ycrcb[:, :, 0].astype(np.float32)

    bits = text_to_bits(WATERMARK_TEXT)
    bit_index = 0

    height, width = y_channel.shape

    for row in range(0, height - 8, 8):
        for col in range(0, width - 8, 8):
            if bit_index >= len(bits):
                break

            block = y_channel[row:row + 8, col:col + 8]
            dct_block = cv2.dct(block)

            bit = bits[bit_index]

            if bit == 1:
                dct_block[4, 3] = abs(dct_block[4, 3]) + STRENGTH
            else:
                dct_block[4, 3] = -abs(dct_block[4, 3]) - STRENGTH

            y_channel[row:row + 8, col:col + 8] = cv2.idct(dct_block)
            bit_index += 1

        if bit_index >= len(bits):
            break

    y_channel = np.clip(y_channel, 0, 255).astype(np.uint8)
    ycrcb[:, :, 0] = y_channel

    watermarked_np = cv2.cvtColor(ycrcb, cv2.COLOR_YCrCb2RGB)
    output = Image.fromarray(watermarked_np)
    output.save(OUTPUT_IMAGE)

    print("Watermark embedded successfully.")
    print(f"Output file: {OUTPUT_IMAGE}")
    print(f"Watermark text: {WATERMARK_TEXT}")


if __name__ == "__main__":
    embed_watermark()
```

## Discussion

The test showed that the watermarking method was suitable for embedding an imperceptible watermark into the image, but it was not robust enough to survive the selected image-to-image editing process.

This result is realistic. Image-to-image generation can make substantial changes to pixel values, textures, lighting, compression patterns, and frequency components. Since the watermark was embedded into image frequency information, the editing process may have altered or removed the signal that the detection script expected to find.

The result demonstrates an important limitation of simple watermarking techniques. A watermark may survive small changes such as light compression or minor colour adjustments, but it may fail when the image is regenerated by an AI model.

---

## Why the Watermark May Have Failed

Possible reasons for failure include:

- the image-to-image tool regenerated many parts of the image;
- lighting changes altered the frequency components used for watermarking;
- compression or resizing may have changed the embedded signal;
- the watermark strength may have been too low;
- the detection method may have been too simple;
- the watermark was not error-corrected;
- the image editing process changed the image more than expected.

The detection confidence of 52.08% is close to random matching for a binary watermark, so the result cannot be treated as reliable detection.

---

## What This Shows About AI Watermarking

This activity shows that imperceptible watermarking is technically possible, but robustness is difficult.

For a watermark to survive AI editing, it needs to be stronger and more resilient than a basic DCT-based approach. Real-world watermarking systems may use:

- redundant embedding;
- stronger frequency-domain methods;
- error-correcting codes;
- spread-spectrum watermarking;
- neural watermarking;
- detection models trained to recognise distorted watermarks;
- robustness testing across resizing, compression, cropping, and regeneration.

This experiment shows why watermarking AI-generated images is an active and challenging area in cybersecurity, digital forensics, and AI governance.

---

## Improvements for a Future Attempt

To improve the chance of watermark survival, the following changes could be made:

1. increase watermark strength;
2. embed the watermark multiple times across the image;
3. use error-correcting codes;
4. use a shorter watermark message;
5. avoid heavy image-to-image edits;
6. avoid resizing or format conversion;
7. test several watermark strengths;
8. compare DCT watermarking with spread-spectrum watermarking;
9. use a more robust detection threshold;
10. test multiple edited outputs and compare results.


This would reduce the number of bits that must survive the editing process.
