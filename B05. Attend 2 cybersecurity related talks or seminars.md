# B5 - Attend 2 Cybersecurity Related Talks or Seminars

---

## Overview

This portfolio entry documents attendance at two cybersecurity-related talks or seminars. 
The talks covered historical cyber investigation, defensive cybersecurity, artificial intelligence, machine learning, anomaly-based intrusion detection systems, and large language models.

## Event 1 - University Computer Club Cybersecurity Tech Talk

### Event Topic

*Into The Cuckoo's Egg* book and the Lawrence Berkeley National Laboratory cyber-intrusion investigation.

### Organiser

University Computer Club.

### Event Summary

This cybersecurity tech talk discussed the story behind *The Cuckoo's Egg*, a well-known cybersecurity investigation involving a small accounting error at the Lawrence Berkeley National Laboratory.

A 75-cent accounting error led systems administrator Clifford Stoll to investigate unusual system activity. 
What first looked like a minor accounting issue eventually developed into a digital spy hunt and helped uncover one of the most significant cyber-intrusions of the decade.

The talk used this historical case to explain how careful observation, persistence, logging, and investigation can reveal serious security incidents.

### Key Concepts Covered

- cyber intrusion investigation;
- log analysis;
- anomaly detection through small inconsistencies;
- attacker persistence;
- early computer security history;
- the importance of system administrators in incident detection;
- how minor technical clues can reveal larger compromises.

### What I Learned

I learned that cybersecurity investigations often begin with small clues. In this case, a 75-cent accounting error was enough to trigger deeper investigation. This shows that defenders should not ignore unusual system behaviour, even when it seems minor.

I also learned that historical cases are useful because they show the foundations of modern incident response. Many current practices, such as reviewing logs, investigating anomalies, and tracing attacker behaviour, were already important in early cybersecurity incidents.

### Cybersecurity Relevance

This event is relevant to defensive cybersecurity because it demonstrates the value of:

- monitoring system activity;
- noticing anomalies;
- investigating unusual events;
- keeping useful logs;
- responding carefully instead of making assumptions.

## Event 2 - AI in Defensive Cybersecurity Talk by Larry Huynh

### Event Topic

AI in Defensive Cybersecurity, Machine Learning, Anomaly-based Intrusion Detection Systems, and Large Language Models.

### Speaker

Larry Huynh.

### Event Summary

This talk focused on how artificial intelligence can be used in defensive cybersecurity. The discussion included machine learning, anomaly-based intrusion detection systems, and large language models.

The event explained how AI can help defenders analyse large amounts of security data, identify unusual behaviour, support detection workflows, and assist with cybersecurity decision-making. It also highlighted that AI systems have limitations and should not be treated as perfect replacements for human security analysts.

### Key Concepts Covered

- artificial intelligence in cybersecurity;
- machine learning for security detection;
- anomaly-based intrusion detection systems;
- identifying unusual behaviour in networks or systems;
- large language models in defensive workflows;
- benefits and limitations of AI-assisted security;
- the importance of human review and validation.

### What I Learned

I learned that AI can support cybersecurity by helping detect patterns that may be difficult for humans to notice manually. For example, anomaly-based intrusion detection systems can look for behaviour that is different from normal activity.

I also learned that AI tools can produce false positives and false negatives. This means defenders still need to review alerts, understand the context, and make careful decisions.

Large language models can help with tasks such as summarising alerts, explaining security concepts, generating reports, and assisting with investigation. However, they must be used carefully because they may make mistakes or provide incomplete information.

### Cybersecurity Relevance

This event is relevant to defensive cybersecurity because AI is increasingly used in modern security operations. Machine learning and anomaly-based detection can help organisations identify suspicious activity, while LLMs can support analysis, documentation, and education.

The talk also reinforced that AI should be used as an assistant, not as a replacement for security judgement.

## Overall Reflection

These two events helped me understand cybersecurity from both historical and modern perspectives.

The *Cuckoo's Egg* talk showed that careful investigation and attention to detail are core skills in cybersecurity. Even a very small accounting error can become an important clue when something unusual is happening in a system.

The AI in Defensive Cybersecurity talk showed how modern defenders can use machine learning, anomaly-based intrusion detection systems, and large language models to assist with security monitoring and analysis. However, the talk also made it clear that AI tools must be used carefully because they can make mistakes and require human validation.

Together, the two talks showed that cybersecurity depends on both human judgement and technical tools. Historical investigation skills are still relevant today, even as modern security teams adopt AI-assisted methods.
